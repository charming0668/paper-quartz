*图 1：(a) 传统 VLA 模型基于图像感知生成动作；(b) 传统世界模型基于当前画面与输入动作预测未来视觉帧；(c) RynnVLA-002 提出的动作世界模型 (Action World Model)，在统一的自回归骨干中无缝融合图像与动作的双向理解与生成。*

### 核心亮点速览
1. **打破 VLA 与世界模型的割裂壁垒**：首次提出全自回归的**动作世界模型 (Action World Model)** 统一范式。单套大模型主干参数同时兼任 VLA 策略规划与环境动力学预测，验证了 VLA 与世界模型之间的**双向正向增强**效应。
2. **离散动作注意力掩码 (Action Attention Masking)**：发现经典自回归因果注意掩码在多步动作块 (Action Chunking) 生成中会导致误差累积与滚雪球漂移。创新性设计了解耦动作块注意掩码，切断动作间自回归依赖，使动作块在同一视觉条件引导下并行独立预测，大幅提升生成稳健度。
3. **混合离散-连续双轨策略 (Hybrid Discrete-Continuous Paradigm)**：针对纯离散 VLA 在真实低样本场景易过拟合、自回归解码慢且动作生硬抖动的问题，引入轻量级连续 Action Transformer 动作头，形成“离散辅助加速收敛 + 连续端到端平滑控制”的双轨协同架构。
4. **无需预训练即刷榜 SOTA**：
   - **LIBERO 仿真基准**：在**完全不进行大规模机器人预训练 (Without Pretraining)** 的严苛设置下，连续动作版本在全套评测中达到 **97.4%** 的平均成功率，超越需要海量跨具身预训练的 OpenVLA-OFT (97.1%)、UniVLA (95.2%) 与 π0 (86.0%)。
   - **真实世界 LeRobot SO100 机械臂实验**：真实台面操作中引入世界模型联合训练使综合成功率**相对提升超 50%**；在复杂多目标与强干扰场景下，成功率超越 GR00T-N1.5 与 π0 达 10%~30%。

## 2. 研究背景与核心痛点：VLA 与世界模型的“双向缺陷”

近年来，视觉-语言-动作 (Vision-Language-Action, VLA) 模型（如 RT-2、OpenVLA、π0、GR00T）成为具身智能领域的主流范式。然而，主流 VLA 架构天然存在三项根本性短板：

1. **缺乏对动作本身的内在表征 (Lack of Action Representation)**：在经典 VLA 中，动作仅作为最末端的输出 Token 存在。模型仅学会了从图像条件映射到动作分类标签，没有形成关于“动作将对周围环境产生何种动力学影响”的内部物理表征。
2. **缺乏未来想象力与因果推演 (Lack of Imagination & Counterfactual Reasoning)**：VLA 无法预判采取某项动作后环境将变成何种状态，无法进行前瞻性验证或试错回溯。
3. **缺乏显式物理世界常识 (Absence of Explicit Physics Prior)**：缺乏对物体接触、重力、碰撞与平衡稳定性的建模，面对抓取失败往往一味机械执行，缺乏依据接触状态自适应重试的能力。

与此相对，**世界模型 (World Models)** 通过学习给定当前画面和动作预测未来图像，拥有优异的物理常识与环境因果推演能力，但世界模型本身通常不具备直接规划动作的策略能力。

为了彻底消除这两大范式之间的功能鸿沟，阿里达摩院团队提出了 **RynnVLA-002**，通过将图像、文本、状态和动作统一离散化至共享词表，在同一个大语言模型框架中共同学习环境物理动力学与动作规划。

## 3. RynnVLA-002 核心方法与统一架构

### 3.1 统一架构总览：动作世界模型 (Action World Model)

![Figure 2: RynnVLA-002 整体架构与联合训练流](https://arxiv.org/html/2511.17502v2/x2.png)
*图 2：RynnVLA-002 总体架构。统一融合 VLA 模型数据流与世界模型数据流，通过共享的 Transformer 参数空间同步学习动作决策与下一帧视觉预测。*

在形式化上，RynnVLA-002 整合了两大核心建模任务：
- **VLA 策略生成**：输入语言任务目标 $l$、机械臂上一时刻本体感知状态 $s_{t-1}$ 以及历史多视角图像观测序列 $o_{t-h:t}$，由策略 $\pi$ 输出动作序列 $a_t$：
  $$a_t \sim \pi(a_t \mid l, s_{t-1}, o_{t-h:t})$$
- **世界模型动力学预测**：输入历史视觉观测 $o_{t-h:t-1}$ 与执行动作 $a_{t-h:t-1}$，预测未来环境图像观测 $\hat{o}_t$：
  $$\hat{o}_t \sim f(o_t \mid o_{t-h:t-1}, a_{t-h:t-1})$$

两者由同一套网络参数 $\psi$ 联合参数化，使得模型既能作为执行器（产生动作），又能作为模拟器（产生视觉未来帧）。

### 3.2 四模态分词与共享词表设计 (Unified Multi-modal Tokenization)

RynnVLA-002 初始化自 **Chameleon** 基础多模态大模型架构。模型构建了包含 65,536 个 Token 的统一离散词表，由四组专用 Tokenizer 协同驱动：

| 模态类型 | 分词机制 (Tokenizer) | 编码细节与表征规模 | 词表归属 |
| :--- | :--- | :--- | :--- |
| **图像 (Image)** | VQ-GAN 离散视觉分词器 | 下采样倍率 16，Codebook 容量 8192。针对特定视觉区域（如人手、操作关键物体）施加感知损失优化。256×256 图像生成 256 个 Token，512×512 图像生成 1024 个 Token | 统一词表 |
| **文本 (Text)** | BPE (Byte Pair Encoding) | 沿用 Chameleon 预训练词表，精准解析复杂自然语言操作指令 | 统一词表 |
| **本体感知状态 (State)** | 连续数值分箱均匀离散化 (Uniform Binning) | 将末端执行器 6 自由度位姿与夹爪开合度各维度映射至 256 个等宽 Bin 之中 | 统一词表 |
| **离散动作 (Discrete Action)** | 连续数值分箱均匀离散化 (Uniform Binning) | 与状态分词器机制一致，将各控制维度线性离散化至 256 个 Bin 中 | 统一词表 |

### 3.3 离散动作块注意力掩码 (Action Attention Masking)

在连续控制中，每次推理输出包含 $K$ 步动作的“动作块 (Action Chunking)”对于平滑执行和控制频率至关重要。但在自回归语言模型中，按照因果掩码（Causal Mask）依次生成动作 Token 时，达摩院团队观察到了**严重的误差级联放大现象**：

原因在于底层多模态 LLM 在预训练期间接触了海量图文数据，动作模态属于后验加入的分布。一旦序列早期生成的动作出现微小偏差，后续因果注意机制会加剧误差，使机器人动作迅速发散失真。

![Figure 3: 三种注意掩码模式对比](https://arxiv.org/html/2511.17502v2/x3.png)
*图 3：(a) 传统因果自回归注意掩码；(b) RynnVLA-002 提出的动作注意力掩码：切断后续动作对前序动作的可见性，强制每个动作均直接依附于多模态上下文；(c) 世界模型沿用因果自回归掩码。*

如上图 3(b) 所示，RynnVLA-002 设计了专用 **动作注意掩码 (Action Attention Mask)**：
- 动作 Token 可以双向关注所有文本、历史图像及本体感知状态；
- 同一动作块内部的不同动作 Token 相互掩码不可见（禁止自回归因果关注）；
- 使得每个动作块内的各步动作完全以视觉上下文为物理锚点独立预测，根除了动作自回归累积漂移。

### 3.4 连续动作生成头：Action Transformer 与混合联合训练

虽然离散动作掩码在仿真环境中表现优越，但在样本量有限、环境动态光照复杂的真实物理机械臂上，离散方案暴露了两大天然劣势：
1. **真实小样本数据易过拟合**：离散高维词表需要庞大数据量支撑；
2. **缺乏轨迹平滑度与推理延迟**：逐个 Token 自回归采样缺乏跨时间步插值平滑，动作生硬顿挫且采样耗时高。

因此，RynnVLA-002 进化为**双轨混合架构 (Hybrid Discrete-Continuous Architecture)**：
- 在主干末端引入轻量级 **Action Transformer Head**。
- 借助可学习的动作查询 (Action Queries)，通过双向注意力与单次前向并行解码，一次性输出连续平滑动作轨迹。
- 采用 L1 范数回归损失 $\mathcal{L}_{conti\_action}$ 监督连续动作头。

### 3.5 训练数据组织与统一损失函数

训练时将 VLA 数据流与世界模型数据流以交织 Batch 进行联合优化：

1. **VLA 数据格式**：
   $$\text{\{text\}} \, \text{\{state\}} \, \underbrace{\text{\{image-front-wrist\}}}_{\times M} \, \overbrace{\underbrace{\text{\{action\}}}_{\times K}}^{\mathcal{L}_{dis\_action}}$$
   语言前缀为 'What action should the robot take to + <task> + ?'。

2. **世界模型数据格式**：
   $$\underbrace{\text{\{images-front-wrist\}} \, \text{\{action\}} \, \overbrace{\text{\{images-front-wrist\}}}^{\mathcal{L}_{img}}}_{\times N}$$
   通用生成提示词为 'Generate the next frame based on the current image and the action.'。

3. **端到端联合训练损失函数**：
   $$\mathcal{L} = \mathcal{L}_{dis} + \alpha \mathcal{L}_{conti} = \mathcal{L}_{dis\_action} + \mathcal{L}_{img} + \alpha \mathcal{L}_{conti\_action}$$
   实验中连续损失权重系数设为 $\alpha = 10$。

## 5. 核心消融实验与机理剖析 (Deep Dive & Ablation Studies)

### 5.1 相互促进机理：世界模型如何赋能 VLA 模型？

![Figure 5: LIBERO 仿真任务中的策略行为对比](https://arxiv.org/html/2511.17502v2/x5.png)
*图 5：LIBERO 放置奶酪入碗任务可视化对比。上方：无世界模型联合训练，机械臂在未抓起奶酪的情况下盲目移向目标碗，直接失败；下方：引入世界模型联合训练，机械臂能实时关注夹取交互，在首次未拿稳时持续自适应重新尝试抓取，直至成功。*

在消融实验中，纯 VLA（不加入世界模型数据）在真实机器人的单目标成功率仅为 30%，多目标仅 10%，干扰环境下完全为 0%。而加入世界模型后，成功率暴增至 **80% / 80% / 50%**。
- **内在机理**：世界模型的下一帧预测目标强制网络理解“夹爪捏紧时物体应当跟随移动”、“物体滑落会导致像素变化”。这一动力学先验赋予了模型**操作重试 (Retry Behaviors)** 的内生反馈能力。

### 5.2 相互促进机理：VLA 如何赋能世界模型？

![Figure 7: 世界模型预测未来画面的视角一致性对比](https://arxiv.org/html/2511.17502v2/x7.png)
*图 7：世界模型视频生成效果对比。基线世界模型（无 VLA 联合训练）在前方相机中预测抓取失败，却在腕部视角预测成功，出现视角语义严重冲突；而 RynnVLA-002 动作世界模型在双重视角下均能生成精准一致的抓取成功画面。*

单纯的世界模型仅根据像素重构损失学习，在多视角下经常产生“前视视角没抓起，腕部视角却显示抓起”的多视角幻觉冲突。VLA 任务中的操作语义理解充当了强有力的跨视角全局状态正则化约束，从根源上消除了视角不一致。

### 5.3 离散动作对连续动作训练的加速效应

![Figure 8: 离散辅助损失对连续动作收敛速度的加速曲线](https://arxiv.org/html/2511.17502v2/figures/performance_plot_final.png)
*图 8：离散动作辅助优化在训练过程中对连续动作生成的收敛加速对比曲线。*

研究团队发现了一项关键工程洞见：**在训练连续 Action Transformer 时，保留主干对离散动作 Token 的交叉熵分类损失 $\mathcal{L}_{dis\_action}$ 具有极强的梯度引导与正则化作用**。
从图 8 可以看到，包含离散动作辅助监督的模型在前 20% 训练步数即可迅速跃升至 80% 以上成功率，其收敛速度和最终性能均显著优于直接用纯连续 L1 损失训练的模型。

### 5.4 腕部相机与本体感知状态的真机必要性验证

在仿真环境中，即便缺少腕部相机或本体状态，模型依靠全局固定俯视视角仍能取得 80%+ 成功率；但达摩院团队指出，**在真实机器人实验中，腕部相机与本体感知状态是不可或缺的刚性输入**：
- 缺少腕部相机时，真机机械臂往往在末端挡住主体时无法判定毫米级抓取对齐；
- 缺少本体感知状态时，模型无法获得夹爪闭合程度与力学状态反馈，无法确定何时应该合爪抬升，真机成功率全部跌至 0%（见真机消融表）。

### 5.5 动作分块长度 (Chunk Size) 与注意掩码影响折线

![Figure 6: 离散动作分块长度与注意掩码机制消融对比](https://arxiv.org/html/2511.17502v2/x6.png)
*图 6：不同动作块长度 (Chunk Length) 下，传统因果掩码 (Vanilla Attention Mask) 与本文提出的动作解耦掩码 (Our Attention Mask) 的成功率对比。*

- 传统因果掩码下，随着动作块长度增加，误差雪崩效应愈演愈烈，性能断崖式下跌；
- 本文解耦注意掩码使模型在动作块长度增加时依然保持稳定高成功率，显著拓展了自回归动作出块的鲁棒工作区间。

![Figure 9: 连续动作与离散动作全过程性能演进对比](https://arxiv.org/html/2511.17502v2/figures/performance_comparison_4plots_row.png)
*图 9：离散动作与连续动作在四大子任务上的收敛速度与平稳性对比，连续动作全面展现出收敛更快、极值更高的综合优势。*

## 6. 局限性与未来探索方向

1. **单步预测限制 (Single Prediction Round)**：为了兼顾计算开销，当前世界模型在联合训练中主要采用一步前向预测（$N=1$），未来可以拓展至多步视频扩散或长程视觉展开 (Long-horizon Rollout)。
2. **更高分辨率视觉理解**：当前采用的 VQ-GAN 分词器将图像下采样至 256 或 512 尺寸，对于微小零部件的精密工业装配仍存在分辨率局限。
3. **闭环在线反思与策略检索 (Model-based Planning)**：目前世界模型主要作为辅助自监督表征参与训练，未来可进一步在测试推理阶段实时生成多条候选路径视觉推演，利用价值评估器实现真正的“想清楚再动手 (Think Before Acting)”。

## 7. 核心要点总结 (Key Takeaways)

1. **统一双模**：RynnVLA-002 证实了 VLA 决策模型与世界模型动力学预测在底层表征上的**共生互补**，世界模型教会 VLA 物理接触常识，VLA 赋能世界模型语义视角一致性。
2. **掩码解耦**：自回归离散动作出块面临严重的误差级联，通过切断动作间自回归依赖、全面对齐多模态上下文的注意掩码，成功攻克自回归动作漂移难题。
3. **混合双轨**：采用“离散 Token 分类辅助加速收敛 + 连续 Transformer 头并行输出平滑轨迹”的工程范式，兼顾了表征学习与真机平滑控制。
4. **卓越性能**：在无任何大规模跨具身数据预训练的前提下，LIBERO 达到 97.4%，并在真实低成本机械臂上展现出对抗遮挡、多目标与杂乱背景的极高稳定性。
